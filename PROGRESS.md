## 🏛 Architectural Principles & Golden Rules

1. **Strict Multi-Window Architecture (Non-SPA)**:
   - Lightweight central **Hub** window acts as the launcher/dashboard.
   - Every standalone tool (Docs, Sheets, Whiteboard, etc.) is spawned as an **isolated OS-level `BrowserWindow`** from the Electron Main process.
   - Crash and memory isolation: A heavy operation or crash in one tool window never brings down the Hub or another tool.

2. **Modular Code Discipline**:
   - Files are strictly capped at **250–300 lines of code**.
   - Components, IPC handlers, stores, and hooks must be decomposed into focused, single-responsibility modules.

3. **Non-Blocking UI Thread**:
   - React UI thread remains fluid at all times.
   - Heavy file I/O, format conversions, and background compute run strictly in the Electron Main process or dedicated worker threads over typed IPC.

4. **End-to-End Type Safety**:
   - Strict TypeScript everywhere.
   - All IPC channels, request payloads, response schemas, and window state contracts are strictly typed across Main, Preload, and Renderer.

5. **Approval Before Heavy Integrations**:
   - Before introducing complex engines (Univer, FFmpeg native binaries, ONNX models), a concise architecture plan will be presented for review.
